## Key Results

### Model Performance
- **DST-GNN** achieved superior performance compared to traditional ML baselines
- Leave-One-Subject-Out (LOSO) cross-validation was used for robust evaluation
- Multi-seed evaluation ensures reproducibility

### Analyses Included

1. **Baseline Models**: SVM, Random Forest, XGBoost, MLP, Logistic Regression
2. **DST-GNN**: Graph Attention Network (GAT) + GRU temporal modeling
3. **Explainability**: 
   - Feature importance (baseline & GNN)
   - Channel importance topomaps
   - Integrated Gradients
   - GNNExplainer edge importance
4. **Multi-Conditional Analysis**:
   - 9 tasks: EC, EO, H, C, S, F, M, ET, R
   - PLI and wPLI connectivity comparison
   - Cross-task brain region discriminability
   - Frequency band significance analysis

### Dataset
- 14 subjects (7 addicted, 7 healthy)
- 19-channel EEG at 250 Hz
- 9 different experimental conditions
